# Event ON 홈페이지 v2

app.py와 requirements.txt를 GitHub의 같은 폴더에 업로드하고 기존 파일을 덮어쓰세요. Streamlit Cloud 실행 파일은 app.py입니다.

홈 중앙 상단 및 왼쪽 메뉴: 대시보드 / AI 보고서 버튼. 두 화면은 아직 연결 전인 안내 화면이며 render_dashboard(), render_ai_report()를 교체하면 됩니다.
왼쪽 아래: 설정 및 사용자 이름. 기본 이름은 사용자입니다. 설정에서 변경하면 현재 Streamlit 세션 동안 유지됩니다. 인증/영구 프로필은 포함하지 않습니다. 모바일에서는 왼쪽 메뉴를 열어 확인하세요.

Python 구문 및 링크 구조는 검사했으며 실제 브라우저 렌더링은 아직 확인하지 못했습니다.
