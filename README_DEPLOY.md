# 바로 실행 가능
이 ZIP에는 빌드된 dist 폴더도 포함되어 있습니다. 압축을 풀어 모든 파일/폴더를 GitHub에 올리고 Streamlit에서 app.py를 실행하세요. 첫 배포에는 별도 빌드가 필요 없습니다. 아래 Actions 안내는 이후 소스 수정 시에만 필요합니다.

# Event ON 통합 배포
1. ZIP을 풀고 안의 파일과 폴더를 그대로 저장소 최상위에 올립니다. src, data, .github 폴더를 빠뜨리지 마세요.
2. GitHub Actions 탭에서 Build Event ON 실행이 끝나는지 확인하세요. 자동 실행이 없다면 workflow_dispatch로 실행합니다. 브랜치 보호/조직 정책 때문에 쓰기가 금지된 경우 관리자 설정이 필요합니다.
3. 빌드 완료 시 dist 폴더가 자동 커밋됩니다. Streamlit 실행 파일을 app.py로 지정하고 재시작합니다.

기존 홈/계정/설정/보고서를 유지하고 대시보드에서 React 3D 화면을 표시합니다.
3D 프로젝트 저장은 원본 브라우저 저장 방식이며 기존 계정 DB와 통합되지 않습니다. Python 분석은 JSON 내보내기/가져오기로 연결합니다.
별도 Express 서버는 Streamlit에서 실행되지 않습니다. 자연어 AI API와 서버 소스 ZIP 다운로드 등 /api 기능은 사용할 수 없으며 원본의 규칙 폴백만 이용할 수 있습니다. 기존 AI 보고서는 템플릿 기반입니다.
밀집도·점수·접근성 평가는 검증된 안전 인증이 아닙니다. SQLite는 Cloud에서 영구 보존이 보장되지 않습니다. PDF 한글 폰트는 기존 코드 상태입니다.
